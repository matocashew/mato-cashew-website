# Knowledge Content Standards

Version: 1.0

Last Updated: 2026-08-04

---

# Purpose

This document defines the writing, structure, SEO, and formatting standards for all articles published in the Mato Cashew Knowledge Center.

These standards ensure that every article maintains consistent quality, readability, and long-term maintainability.

---

# Knowledge Center Mission

The Knowledge Center is not a blog.

It is a professional knowledge base that educates customers, buyers, importers, retailers, food manufacturers, and anyone interested in the cashew industry.

Every article should provide practical, trustworthy, and well-structured information.

---

# Article Types

## Type A — Foundation Article

Purpose

Introduce a core concept.

Examples

- What is Cashew?
- Cashew Tree

---

## Type B — Process Guide

Purpose

Explain a process step-by-step.

Examples

- Complete Guide to Cashew Processing
- Food Safety in Cashew Processing

---

## Type C — Reference Article

Purpose

Explain standards, classifications, specifications, or technical information.

Examples

- Cashew Grading Standards
- Export Quality Standards

---

## Type D — Business Guide

Purpose

Help buyers or customers make decisions.

Examples

- Export FAQ
- Buying Guide

---

# Required Frontmatter

Every article must include:

- title
- description
- excerpt
- slug
- publishedAt
- author
- heroImage
- tags
- category
- featured
- draft
- readingTime
- language
- seo

---

# Required Sections

Every article should contain:

1. Introduction

2. Main Content

3. At least one InfoBox

4. At least one table (when appropriate)

5. FAQ

6. Continue Learning

---

# Writing Style

Articles should be:

- Professional
- Educational
- Easy to understand
- Fact-based
- Neutral
- Reader-focused

Avoid:

- Marketing language
- Unsupported claims
- Keyword stuffing

---

# Internal Linking

Each article should link to at least two related articles.

Example:

Processing Guide

→ What is Cashew?

→ Cashew Tree

→ Cashew Grading Standards

---

# Components

Approved components:

- InfoBox
- FAQ
- ComparisonTable
- ArticleLink

New components should only be introduced when reusable across multiple articles.

---

# Images

Every article should include:

- Hero Image
- Descriptive Alt Text

Images should support the content and improve understanding.

---

# Tables

Use tables when comparing:

- Grades
- Specifications
- Standards
- Equipment
- Product Types

---

# SEO Guidelines

Every article must:

- Have one H1
- Use logical H2/H3 headings
- Include natural keywords
- Include internal links
- Have a unique meta description

---

# Content Quality Checklist

Before publishing, verify:

✓ Frontmatter completed

✓ Grammar reviewed

✓ Links tested

✓ Components rendered correctly

✓ Build successful

✓ Images displayed correctly

✓ Reading flow is clear

✓ SEO metadata completed

---

# Long-term Goal

The Knowledge Center should grow into a comprehensive digital reference for the global cashew industry.

Every new article should strengthen the knowledge network through clear structure and meaningful internal links.
