# Cashew Packaging Guide — Asset Plan

## Sprint
Sprint 12

## Strategy
Create only visuals that improve comprehension. Keep standards/comparison data in HTML components.

## Asset 1 — Hero Banner
**Status: Required**

### Direction
Finished cashew kernels in a professional packaging / quality-preservation context: clean kernels, sealed food packaging, packaging/QC workspace, flexible barrier pouch and/or commercial container, subtle distribution context.

### Avoid
Generic warehouse-only imagery; one format shown as universally required; fake certification marks; “best packaging” claims; unsupported shelf-life claims; fixed gas percentages as hero claims; hermetic and vacuum shown as synonyms.

### Suggested neutral text
`Cashew Packaging Guide` or `Protecting Quality Through Packaging`

### Alt-text intent
`Finished cashew kernels with sealed food packaging in a professional quality-control setting.`

### Likely filename
`cashew-packaging-guide.jpg`

## Asset 2 — Packaging System Diagram
**Status: Recommended**

### Flow
Cashew Kernels → Primary Package → Secondary Package → Transport Package → Storage / Distribution

### Note
Conceptual only; not every supply chain uses three physically distinct layers.

### Caption
“Conceptual packaging-system layers. The exact configuration depends on product, buyer, market, and distribution requirements.”

### Likely filename
`cashew-packaging-system.jpg`

## Asset 3 — Protection Diagram
**Status: Optional**

Show packaging as an interface against moisture, oxygen, contamination, and physical damage. Create only if MDX remains difficult to scan after using existing components.

## Do not create
- AFI vs UNECE infographic — use `ComparisonTable`.
- Vacuum vs MAP “winner” graphic.
- Universal film/laminate construction graphic.
- Shelf-life timeline graphic.

## Accessibility
Meaningful alt text; essential technical information remains HTML; diagram labels readable on mobile; AFI/UNECE distinctions not image-only.

## Factual safeguards
- [ ] No visual calls vacuum universally best.
- [ ] No visual says nitrogen is universally required.
- [ ] No AFI gas percentage presented globally.
- [ ] Hermetic and vacuum not depicted as synonyms.
- [ ] No universal film structure.
- [ ] No unsupported shelf-life guarantee.
- [ ] No fake certification/standard marks.
