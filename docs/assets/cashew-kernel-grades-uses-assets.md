# Cashew Kernel Grades & Uses — Asset Plan

## Sprint
Sprint 15

## Asset 1 — Hero Banner
**Status: Required**

### Purpose
Show different cashew kernel forms and sizes in a clean buyer/commercial selection context.

### Visual direction
- whole kernels in visibly different size groups;
- splits / pieces shown separately;
- quality-control / buyer-specification context;
- premium, clean commercial presentation.

### Avoid
- “W180 = best”
- “W320 = standard”
- fixed grade-to-food labels
- unsupported price/premium ladder
- size shown as a quality pyramid
- fake certification badges

### Suggested text
`Cashew Kernel Grades & Uses`
`Size, Quality, and Buyer Selection`

### Likely filename
`cashew-kernel-grades-uses.jpg`

**Status: Recommended**

Caption:
“Conceptual buyer-selection flow. The suitable cashew specification depends on intended use, kernel form, size, quality, technical requirements, processing needs, packaging, and buyer/market requirements.”
