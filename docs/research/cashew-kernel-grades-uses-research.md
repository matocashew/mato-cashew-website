# Cashew Kernel Grades & Uses — Research Notes

## Sprint
Sprint 15

## Working title
**Cashew Kernel Grades & Uses: Size, Quality, and Buyer Selection**

## Core research conclusion
Buyer selection should be based on:

Intended application + kernel form + size requirement + quality class + technical specification + process performance + packaging / market requirement → agreed commercial specification.

## Key findings

### Kernel form
Both UNECE and AFI distinguish:
- Whole
- Butts
- Splits
- Pieces

Use kernel form according to presentation or manufacturing need.

### Size is not quality
Whole-kernel size codes describe size/count relationships. They do not by themselves define colour, defects, food-safety status, taste, or total quality.

**Core rule:** Size ≠ complete quality.

### Common whole-kernel size codes
Common designations include 180, 210, 240, 320, and 450. UNECE DDP-17 also includes codes such as 150 and 500.

AFI count context:
- 180: about 140–180 kernels/lb
- 210: about 180–210 kernels/lb
- 240: about 220–240 kernels/lb
- 320: about 300–320 kernels/lb
- 450: about 400–450 kernels/lb

Lower count generally corresponds to larger whole kernels.

**Safeguard:** Larger ≠ automatically higher quality or better suitability.

### Quality terminology differs
UNECE uses:
- Extra
- Class I
- Class II

AFI uses terminology including:
- First Quality Fancy
- Second Quality Scorched
- Third Quality Special Scorched
- Lightly Blemished
- Dessert / Blemished categories

Do not create an unsupported direct equivalence between UNECE and AFI quality classes.

### Piece terminology is specification-specific
UNECE and AFI do not use identical piece taxonomies. Always identify the applicable specification or buyer standard.

### Manufacturing/application guidance
Evidence supports choosing form and piece size according to manufacturing purpose, but it does **not** support rigid mappings such as:
- W320 = retail
- W450 = bakery
- LP = confectionery

Use functional guidance instead:
- intact presentation → consider whole kernels;
- half/broken form → consider split/butt;
- ingredient pieces → select a specified piece size.

### Process performance
AFI roast-test guidance supports considering performance after roasting where relevant.

Do not claim one W-number automatically roasts better than another.

## Buyer selection framework
1. Define intended application.
2. Select kernel form.
3. Select size requirement.
4. Define quality class / colour / defects / tolerances.
5. Define technical requirements such as moisture and safety.
6. Consider process performance where relevant.
7. Select packaging.
8. Confirm buyer / market requirements.
9. Agree commercial specification.
