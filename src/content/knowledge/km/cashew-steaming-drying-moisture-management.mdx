## អ្វីដែលការស្រាវជ្រាវបានរកឃើញ

ការសិក្សាឆ្នាំ **2026** ដោយ Diallo និងសហការី បានសិក្សាអំពីការផ្ទេរកម្តៅ និងម៉ាសក្នុងគ្រាប់ស្វាយចន្ទី ក្នុងអំឡុងការចំហុយ និងការសម្ងួត។

អ្នកស្រាវជ្រាវបានពិនិត្យការផ្លាស់ទីរបស់ទឹក និងចំហាយទឹកក្នុងអំឡុងការត្រាំ ការចំហុយ និងការសម្ងួត។ ការសិក្សាបានកំណត់ថា តំបន់ **hilum** របស់គ្រាប់ស្វាយចន្ទីមានតួនាទីសំខាន់មួយក្នុងការផ្ទេរសំណើម។

## ហេតុអ្វីការគ្រប់គ្រងសំណើមមុនការបកសំបកមានសារៈសំខាន់?

ដំណើរការកែច្នៃស្វាយចន្ទីអាចសង្ខេបបានជា៖

**គ្រាប់ស្វាយចន្ទីឆៅ → ការរៀបចំគ្រាប់ → ការចំហុយ → ការសម្ងួត/ទុកឱ្យស្ថានភាពគ្រាប់សមស្រប → ការបកសំបក → ការសម្ងួតសាច់គ្រាប់ → ការបកស្បែក → ការតម្រៀបគុណភាព**

ការចំហុយផ្តល់កម្តៅ និងធ្វើឱ្យស្ថានភាពសំណើមរបស់គ្រាប់ផ្លាស់ប្តូរ។ ការសម្ងួត ឬការរៀបចំគ្រាប់បន្ទាប់ពីនោះ ធ្វើឱ្យស្ថានភាពរបស់គ្រាប់ផ្លាស់ប្តូរម្តងទៀត មុនការបកសំបក។

ដូច្នេះ អ្នកកែច្នៃគួរមើលដំណាក់កាលទាំងនេះជាដំណើរការដែលមានទំនាក់ទំនងគ្នា ជាជាងមើលម៉ាស៊ីន ឬប្រតិបត្តិការនីមួយៗដោយដាច់ដោយឡែក។

- ការសង្កេតរបស់អ្នកប្រតិបត្តិការ។

### 3. កត់ត្រាការសម្ងួត ឬការទុកគ្រាប់

អាចកត់ត្រា៖

- រយៈពេលសម្ងួត ឬទុកគ្រាប់;
- វិធីសាស្ត្រសម្ងួត;
- លក្ខខណ្ឌបរិស្ថាន ឬឧបករណ៍ដែលពាក់ព័ន្ធ; និង
- ការវាស់សំណើម ប្រសិនបើសមស្រប។

### 4. ប្រៀបធៀបលទ្ធផលក្រោយការបកសំបក

ទិន្នន័យមានប្រយោជន៍ជាងមុន ប្រសិនបើភ្ជាប់ជាមួយលទ្ធផលដូចជា៖

- សាច់គ្រាប់ពេញ;
- សាច់គ្រាប់បែក;
- គ្រាប់ដែលត្រូវបដិសេធ;
- គ្រាប់ដែលពិបាកបក; និង
- ការសង្កេតគុណភាពផ្សេងៗ។

នៅពេលមានទិន្នន័យពី batch ច្រើន អ្នកកែច្នៃអាចចាប់ផ្តើមយល់ថា វត្ថុធាតុដើម និងលក្ខខណ្ឌកែច្នៃបែបណា មានទំនាក់ទំនងជាមួយលទ្ធផលផលិតកម្មដែលមានស្ថិរភាពជាង។

## សម្រាប់អ្នកកែច្នៃខ្នាតតូច និងអាជីវកម្មគ្រួសារ

ការចាប់ផ្តើមតាមដានដំណើរការផលិត មិនចាំបាច់ត្រូវមានប្រព័ន្ធឌីជីថលស្មុគស្មាញទេ។

អាចចាប់ផ្តើមដោយប្រើ batch sheet សាមញ្ញ៖

**វត្ថុធាតុដើម → ទំហំ/grade → ស្ថានភាពដំបូង → ការចំហុយ → ការសម្ងួត/ទុកគ្រាប់ → ការបកសំបក → គ្រាប់ពេញ → គ្រាប់បែក → reject**

បន្ទាប់ពីកត់ត្រាបាន batch ច្រើន អ្នកកែច្នៃអាចប្រៀបធៀបលទ្ធផលជាក់ស្តែង ជំនួសឱ្យការពឹងផ្អែកតែលើការចងចាំរបស់អ្នកប្រតិបត្តិការ។

## កម្រិតនៃព័ត៌មាននេះ

ការស្រាវជ្រាវដែលបានពិភាក្សានៅទីនេះជួយបង្កើនការយល់ដឹងអំពីការផ្ទេរសំណើម និងកម្តៅក្នុងការកែច្នៃស្វាយចន្ទី។

ប៉ុន្តែវា **មិនបានកំណត់រយៈពេលចំហុយ រយៈពេលសម្ងួត សីតុណ្ហភាព ឬគោលដៅសំណើមសកលតែមួយ** ដែលសមស្របសម្រាប់គ្រប់ពូជ ទំហំគ្រាប់ ម៉ាស៊ីន រោងចក្រ និងអាកាសធាតុនោះទេ។

អ្នកកែច្នៃគួរផ្ទៀងផ្ទាត់លក្ខខណ្ឌប្រតិបត្តិការជាមួយវត្ថុធាតុដើម ឧបករណ៍ ប្រព័ន្ធសុវត្ថិភាពអាហារ និងតម្រូវការអ្នកទិញរបស់ខ្លួន។
