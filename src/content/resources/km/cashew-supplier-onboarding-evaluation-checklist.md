# បញ្ជីត្រួតពិនិត្យ និងទម្រង់វាយតម្លៃអ្នកផ្គត់ផ្គង់ស្វាយចន្ទី៖ ឧបករណ៍សម្រាប់អ្នកទិញ

ការទិញគ្រាប់ស្វាយចន្ទីដែលមានគុណភាពល្អ ចាប់ផ្តើមមុនពេលទំនិញមកដល់ឃ្លាំង។ អ្នកទិញត្រូវដឹងថា អ្នកណាជាអ្នកផ្គត់ផ្គង់ គ្រាប់ស្វាយចន្ទីមានប្រភពពីណា ត្រូវបានរក្សាទុកយ៉ាងដូចម្តេច និងតើអ្នកផ្គត់ផ្គង់អាចដឹកជញ្ជូនទាន់ពេល និងផ្តល់កំណត់ត្រាច្បាស់លាស់បានដែរឬទេ។ បើគ្មានទម្រង់វាយតម្លៃច្បាស់លាស់ ការសម្រេចចិត្តអាចខុសគ្នាតាមអ្នកវាយតម្លៃ និងខកខានចំណុចត្រូវកែលម្អ។

ធនធាននេះរបស់ **ចន្ទីមាតុភូមិ (Mato Cashew)** ផ្តល់ **ឧបករណ៍វាយតម្លៃ និងចុះបញ្ជីអ្នកផ្គត់ផ្គង់** ដែលអាចកែសម្រួលបាន សម្រាប់សហគមន៍កសិកម្ម ស្ថានីយទិញ អ្នកប្រមូលទិញ រោងចក្រកែច្នៃ និងអាជីវកម្មទិញស្វាយចន្ទី។ នេះជាឧបករណ៍គ្រប់គ្រងការទិញ និងកំណត់ត្រា មិនមែនជាមេរៀនបច្ចេកទេសកែច្នៃ វិញ្ញាបនបត្រ ឬការធានាថាបានបំពេញច្បាប់គ្រប់យ៉ាងនោះទេ។

## តើអ្នកណាគួរប្រើឧបករណ៍នេះ?

ឧបករណ៍នេះសមស្របសម្រាប់អ្នកទិញពីកសិករម្នាក់ៗ ក្រុមកសិករ សហគមន៍ អ្នកប្រមូលទិញ និងអ្នកផ្គត់ផ្គង់គ្រាប់ស្វាយចន្ទីឆៅ ឬគ្រាប់ចន្ទីកែច្នៃ។ អាជីវកម្មខ្នាតតូចអាចប្រើជាទម្រង់វាយតម្លៃដំបូង ខណៈអាជីវកម្មធំអាចកែសម្រួលតាមគោលការណ៍ទិញ និងតម្រូវការអតិថិជនរបស់ខ្លួន។

សម្រាប់កសិករខ្នាតតូច គួរស្នើសុំភស្តុតាងឱ្យសមស្របនឹងស្ថានភាពជាក់ស្តែង។ ព័ត៌មានទីតាំងកសិដ្ឋាន លេខទំនាក់ទំនង ប្រវត្តិទិញលក់ និងការបញ្ជាក់ពីសហគមន៍ អាចមានប្រយោជន៍ជាងការទាមទារឯកសារសម្រាប់ក្រុមហ៊ុនធំៗ។

## ព័ត៌មានដែលត្រូវកត់ត្រាមុនអនុម័តអ្នកផ្គត់ផ្គង់

ចាប់ផ្តើមដោយកត់ឈ្មោះ ឬលេខសម្គាល់អ្នកផ្គត់ផ្គង់ ព័ត៌មានទំនាក់ទំនង តំបន់ប្រភព ប្រភេទផលិតផល សមត្ថភាពផ្គត់ផ្គង់ប្រហាក់ប្រហែល ឈ្មោះអ្នកវាយតម្លៃ និងកាលបរិច្ឆេទ។ រក្សាឯកសារគាំទ្រឱ្យបានច្បាស់លាស់។ បើអាចធ្វើបាន សូមភ្ជាប់លេខសម្គាល់អ្នកផ្គត់ផ្គង់ទៅនឹងបង្កាន់ដៃទិញលក់ លទ្ធផលត្រួតពិនិត្យគុណភាព និង **សៀវភៅកត់ត្រាតាមដានប្រភព និងចលនាឡូត៍ស្វាយចន្ទី**។

ប្រើលក្ខណៈវិនិច្ឆ័យដូចគ្នាចំនួនប្រាំសម្រាប់អ្នកផ្គត់ផ្គង់នីមួយៗ៖

| លក្ខណៈវិនិច្ឆ័យ | ទម្ងន់ |
| --- | ---: |
| អត្តសញ្ញាណអ្នកផ្គត់ផ្គង់ និងប្រភពផលិតផល | 25% |
| គុណភាពផលិតផល និងការរក្សាទុក | 25% |
| ភាពទៀងទាត់នៃការដឹកជញ្ជូន និងកំណត់ត្រា | 20% |
| ការអនុវត្តប្រកបដោយទំនួលខុសត្រូវ | 20% |
| លក្ខខណ្ឌពាណិជ្ជកម្ម និងសមត្ថភាពផ្គត់ផ្គង់ | 10% |
| **សរុប** | **100%** |

**អត្តសញ្ញាណ និងប្រភព៖** តើអាចស្គាល់អ្នកផ្គត់ផ្គង់ និងបញ្ជាក់ប្រភពគ្រាប់ស្វាយចន្ទីបានសមហេតុផលដែរឬទេ? កត់ត្រាព័ត៌មានដែលនៅខ្វះ។

**គុណភាព និងការរក្សាទុក៖** តើមានការការពារពីសំណើម សត្វល្អិត ភាពកខ្វក់ និងលក្ខខណ្ឌស្តុកមិនសមស្របដែរឬទេ? ការអនុម័តអ្នកផ្គត់ផ្គង់មិនអាចជំនួសការត្រួតពិនិត្យឡូត៍ទំនិញនីមួយៗបានទេ។

**ការដឹកជញ្ជូន និងកំណត់ត្រា៖** តើអ្នកផ្គត់ផ្គង់អាចផ្គត់ផ្គង់បរិមាណដែលបានព្រមព្រៀង និងរក្សាបង្កាន់ដៃ លេខឡូត៍ និងកាលបរិច្ឆេទទិញលក់បានដែរឬទេ?

**ការអនុវត្តប្រកបដោយទំនួលខុសត្រូវ៖** តើមានក្តីបារម្ភដែលគួរឱ្យជឿទុកចិត្តអំពីសុវត្ថិភាពការងារ លក្ខខណ្ឌការងារ ឬបរិស្ថានដែរឬទេ? បញ្ហាធ្ងន់ធ្ងរដែលមិនទាន់ដោះស្រាយត្រូវពិនិត្យបន្ថែម ទោះបីពិន្ទុសរុបខ្ពស់ក៏ដោយ។

**លក្ខខណ្ឌពាណិជ្ជកម្ម៖** តើបរិមាណ តម្លៃ លក្ខខណ្ឌទូទាត់ ការទំនាក់ទំនង និងវិធីដោះស្រាយវិវាទមានភាពច្បាស់លាស់ដែរឬទេ?

## របៀបផ្តល់ពិន្ទុ

សម្រាប់លក្ខណៈវិនិច្ឆ័យនីមួយៗ ផ្តល់ពិន្ទុ **០, ១ ឬ ២**៖

- **០ — មិនគ្រប់គ្រាន់៖** ខ្វះភស្តុតាង ឬមិនទាន់បំពេញលក្ខខណ្ឌ។
- **១ — បំពេញមួយផ្នែក៖** មានភស្តុតាងខ្លះ ប៉ុន្តែត្រូវការកែលម្អ ឬផ្ទៀងផ្ទាត់បន្ថែម។
- **២ — ពេញចិត្ត៖** មានភស្តុតាងសមហេតុផលគាំទ្រលក្ខណៈវិនិច្ឆ័យ។

គណនាពិន្ទុតាមរូបមន្ត **(ពិន្ទុដែលទទួលបាន ÷ ២) × ទម្ងន់**។ ឯកសារ Excel អាចប្រើសម្រាប់កត់ត្រា និងគណនាពិន្ទុសរុបតាមទម្ងន់។

| ពិន្ទុសរុប | សេចក្តីសម្រេចណែនាំសម្រាប់ផ្ទៃក្នុង |
| --- | --- |
| 80–100 | អាចអនុម័ត បន្ទាប់ពីពិនិត្យហានិភ័យធ្ងន់ធ្ងរ |
| 60–79 | អនុម័តដោយមានលក្ខខណ្ឌ និងផែនការកែលម្អ |
| ក្រោម 60 | មិនទាន់អនុម័ត ត្រូវដោះស្រាយចំណុចខ្វះខាត |
| មានហានិភ័យធ្ងន់ធ្ងរមិនទាន់ដោះស្រាយ | ផ្អាកការអនុម័ត និងពិនិត្យបន្ថែម |

កម្រិតពិន្ទុទាំងនេះគ្រាន់តែជា **គំរូសម្រាប់ការគ្រប់គ្រងផ្ទៃក្នុង** មិនមែនជាកម្រិតកំណត់ផ្លូវការរបស់ច្បាប់ ឬស្តង់ដារវិញ្ញាបនបត្រឡើយ។ ពិន្ទុខ្ពស់មិនអាចលុបបំបាត់ហានិភ័យធ្ងន់ធ្ងរផ្នែកសុវត្ថិភាពម្ហូបអាហារ ការងារ ឬបរិស្ថានដែលមិនទាន់ដោះស្រាយបានទេ។ អ្នកគ្រប់គ្រងត្រូវទទួលខុសត្រូវលើសេចក្តីសម្រេចចុងក្រោយ។
