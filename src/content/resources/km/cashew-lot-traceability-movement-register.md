# សៀវភៅកត់ត្រាតាមដានប្រភព និងចលនាឡូត៍ស្វាយចន្ទី៖ គំរូអនុវត្តពីអ្នកផ្គត់ផ្គង់ដល់អ្នកទិញ

គ្រាប់ស្វាយចន្ទីឆៅមួយឡូត៍អាចឆ្លងកាត់ការទិញ ការរក្សាទុក ការកែច្នៃ ការវេចខ្ចប់ និងការដឹកជញ្ជូន មុនទៅដល់អតិថិជន។ ប្រសិនបើកំណត់ត្រាទាំងនេះនៅរាយប៉ាយតាមសៀវភៅផ្សេងៗ អាជីវកម្មអាចពិបាកឆ្លើយសំណួរសំខាន់ៗបី៖ **គ្រាប់ស្វាយចន្ទីនេះមកពីណា? បានឆ្លងកាត់ដំណាក់កាលអ្វីខ្លះ? ហើយបានបញ្ជូនទៅអ្នកណា?**

ធនធាននេះរបស់ **ចន្ទីមាតុភូមិ (Mato Cashew)** ផ្តល់គំរូសៀវភៅកត់ត្រាតាមដានប្រភព និងចលនាឡូត៍ សម្រាប់កសិករ ស្ថានីយទិញ សហគមន៍កសិកម្ម និងអ្នកកែច្នៃខ្នាតតូច។ វាជាឧបករណ៍គ្រប់គ្រងកំណត់ត្រា មិនមែនជាមេរៀនបច្ចេកទេសកែច្នៃ ឬប្រព័ន្ធធានាសុវត្ថិភាពម្ហូបអាហារពេញលេញនោះទេ។

## អត្ថប្រយោជន៍នៃសៀវភៅកត់ត្រានេះ

សៀវភៅនេះជួយភ្ជាប់ព័ត៌មានពីឡូត៍គ្រាប់ឆៅដែលទទួលចូល ទៅកាន់ឡូត៍កែច្នៃ ផលិតផលដែលវេចខ្ចប់ និងការដឹកជញ្ជូនដល់អតិថិជន។ អាជីវកម្មអាចប្រើវាដើម្បីតាមដានចលនាស្តុក ស្រាវជ្រាវបណ្តឹងគុណភាព កំណត់ទីតាំងទំនិញដែលអាចពាក់ព័ន្ធនឹងបញ្ហា និងបង្ហាញប្រវត្តិទំនិញដល់អ្នកទិញ។

គោលការណ៍ចាប់ផ្តើមដែលអាចអនុវត្តបានគឺ **ដឹងប្រភពមួយជំហានថយក្រោយ** (អ្នកផ្គត់ផ្គង់ផ្ទាល់) និង **ដឹងទិសដៅមួយជំហានទៅមុខ** (អតិថិជនផ្ទាល់) ព្រមទាំងរក្សាទំនាក់ទំនងរវាងឡូត៍នៅក្នុងដំណើរការកែច្នៃ។ កំណត់ត្រាតាមដានប្រភពជួយដល់ការស្រាវជ្រាវ និងការត្រៀមខ្លួនពេលចាំបាច់ត្រូវប្រមូលទំនិញត្រឡប់មកវិញ ប៉ុន្តែមិនមែនជាភស្តុតាងបញ្ជាក់ថាផលិតផលមានសុវត្ថិភាព ឬទទួលបានវិញ្ញាបនបត្រណាមួយឡើយ។

## ១. កំណត់លេខសម្គាល់ពិសេសសម្រាប់ឡូត៍ដែលទទួលចូល

នៅពេលទទួលទំនិញ ត្រូវផ្តល់លេខសម្គាល់ឡូត៍ (Lot ID) មិនឱ្យស្ទួន។ ឧទាហរណ៍ `RCN-261019-001` អាចសម្គាល់ការទទួលគ្រាប់ស្វាយចន្ទីឆៅមួយឡូត៍នៅថ្ងៃទី១៩ ខែតុលា ឆ្នាំ២០២៦។ នេះគ្រាន់តែជាគំរូលេខសម្គាល់ផ្ទៃក្នុងប៉ុណ្ណោះ អាជីវកម្មអាចកំណត់របៀបផ្សេងបាន ដោយរក្សាឱ្យមានភាពច្បាស់លាស់ និងមិនស្ទួន។

ត្រូវកត់ត្រាឈ្មោះ ឬលេខសម្គាល់អ្នកផ្គត់ផ្គង់ ទីតាំងប្រភព កាលបរិច្ឆេទ ប្រភេទទំនិញ ទម្ងន់សុទ្ធគិតជាគីឡូក្រាម ទីតាំងស្តុក និងលេខយោងវិក្កយបត្រ ឬប័ណ្ណប្រគល់ទំនិញ។ លេខឡូត៍នៅលើបាវ ឬស្លាកស្តុកត្រូវតែត្រូវគ្នានឹងកំណត់ត្រា។ ប្រសិនបើទំនិញមួយជើងមានប្រភពផ្សេងៗគ្នាដែលអាចបែងចែកបាន គួររក្សាព័ត៌មានប្រភពឱ្យដាច់ពីគ្នា ដើម្បីជៀសវាងការកត់ត្រាប្រភពមិនត្រឹមត្រូវ។

សម្រាប់ការវាស់សំណើម ការពិនិត្យកំហូច និងការសម្រេចទទួល ឬបដិសេធទំនិញ សូមប្រើ **បញ្ជីត្រួតពិនិត្យគុណភាពគ្រាប់ស្វាយចន្ទីឆៅ** ដែលបានរៀបចំរួច ហើយកត់តែលេខយោងរបាយការណ៍ពិនិត្យនៅក្នុងសៀវភៅនេះ។

## ២. កត់ត្រាចលនា និងការប្រែប្រួលឡូត៍

រាល់ពេលផ្ទេរទីតាំង បញ្ចេញចូលផលិតកម្ម កែច្នៃ បែងចែក បញ្ចូលឡូត៍ចូលគ្នា វេចខ្ចប់ ផ្អាកទុក អនុញ្ញាតឱ្យចេញ ឬបោះចោល ត្រូវកត់កាលបរិច្ឆេទ បរិមាណ ទីតាំង អ្នកទទួលខុសត្រូវ និងឯកសារយោង។ ចំណុចសំខាន់គឺរក្សាទំនាក់ទំនងរវាង **លេខឡូត៍ចូល** និង **លេខឡូត៍ ឬបាច់ផលិតកម្មចេញ**។

ឧទាហរណ៍ ប្រសិនបើបញ្ចូល `RCN-261019-001` និង `RCN-261019-002` ដើម្បីកែច្នៃជាបាច់ `PROC-261020-001` ត្រូវកត់ពីរជួរ ដោយភ្ជាប់ឡូត៍ឆៅទាំងពីរទៅបាច់កែច្នៃតែមួយ។ ប្រសិនបើបាច់កែច្នៃមួយត្រូវបែងចែកជាឡូត៍វេចខ្ចប់ច្រើន ក៏ត្រូវកត់ទំនាក់ទំនងនីមួយៗដាច់ដោយឡែក។

មិនគួរសន្មតថាទម្ងន់ចូល និងទម្ងន់ចេញស្មើគ្នាក្រោយការបកសំបក សម្ងួត ឬចាត់ថ្នាក់ឡើយ។ ត្រូវបញ្ជាក់ដំណាក់កាលដែលបានថ្លឹង និងឯកតា ហើយរក្សាកំណត់ត្រាផលិតកម្មសម្រាប់ពន្យល់អំពីការបាត់បង់ទម្ងន់ កាកសំណល់ អនុផល និងការកែតម្រូវផ្សេងៗ។

## ៣. ភ្ជាប់ឡូត៍ផលិតផលសម្រេចទៅការដឹកជញ្ជូន

មុនបញ្ជូនទំនិញ ត្រូវកត់លេខឡូត៍ផលិតផលសម្រេច ប្រភេទ និងថ្នាក់គុណភាព បរិមាណ កាលបរិច្ឆេទដឹកជញ្ជូន ឈ្មោះ ឬលេខសម្គាល់អតិថិជន ទីតាំងទទួល លេខវិក្កយបត្រ ឬប័ណ្ណដឹកជញ្ជូន និងអ្នកអនុញ្ញាតឱ្យបញ្ចេញទំនិញ។ ប្រសិនបើការដឹកជញ្ជូនមួយមានឡូត៍ច្រើន ត្រូវកត់មួយជួរសម្រាប់ឡូត៍នីមួយៗ។

ស្លាកលើផលិតផល ឬវេចខ្ចប់ខាងក្រៅគួរបង្ហាញលេខឡូត៍តាមលក្ខណៈសមស្រប និងតាមតម្រូវការស្លាកសញ្ញាដែលអនុវត្ត។ វាជួយភ្ជាប់បណ្តឹងពីអតិថិជនត្រឡប់ទៅកំណត់ត្រាផលិតកម្ម និងការទទួលគ្រាប់ឆៅ។

## ៤. សាកល្បងថាតើអាចតាមដានបានពិតប្រាកដឬទេ

ជ្រើសរើសឡូត៍ផលិតផលមួយដែលបានលក់រួច ហើយសាកល្បងតាមដានថយក្រោយទៅបាច់កែច្នៃ និងឡូត៍គ្រាប់ឆៅទាំងអស់ដែលបានប្រើ។ បន្ទាប់មកជ្រើសរើសឡូត៍គ្រាប់ឆៅមួយ ហើយតាមដានទៅមុខរកឡូត៍ផលិតផល និងអតិថិជនទាំងអស់ដែលពាក់ព័ន្ធ។

ប្រសិនបើមានព័ត៌មានខ្វះ ត្រូវកែលម្អរបៀបកត់ត្រា និងរក្សាប្រវត្តិនៃការកែតម្រូវ មិនគួរលុបព័ត៌មានចាស់ដោយគ្មានសេចក្តីពន្យល់ឡើយ។ រយៈពេលរក្សាឯកសារគួរកំណត់ដោយផ្អែកលើច្បាប់ពាក់ព័ន្ធ លក្ខខណ្ឌអ្នកទិញ និងតម្រូវការប្រតិបត្តិការ មិនគួរសន្មតថាអាជីវកម្មទាំងអស់មានរយៈពេលរក្សាឯកសារដូចគ្នានោះទេ។

## ឧទាហរណ៍៖ ពីឡូត៍គ្រាប់ឆៅដល់អតិថិជន

**តួលេខខាងក្រោមគ្រាន់តែជាឧទាហរណ៍សម្រាប់បង្ហាញរបៀបកត់ត្រា** មិនមែនជាអត្រាទិន្នផល ឬស្តង់ដារគុណភាពស្វាយចន្ទីឡើយ។

| កំណត់ត្រា | ឧទាហរណ៍ |
| --- | --- |
| ឡូត៍ទទួលចូល | `RCN-261019-001` ពីអ្នកផ្គត់ផ្គង់ A គ្រាប់ឆៅ 500 គីឡូក្រាម |
| ភ្ជាប់ទៅផលិតកម្ម | `RCN-261019-001` → `PROC-261020-001` បញ្ចេញ 500 គីឡូក្រាម |
| ផលិតផលសម្រេច | `PROC-261020-001` → `PK-261021-001` គ្រាប់ស្នូលដែលអាចលក់បាន 110 គីឡូក្រាម |
| ដឹកជញ្ជូន | `PK-261021-001` → អតិថិជន B ចំនួន 70 គីឡូក្រាម យោង `DN-001` |
| ស្តុកនៅសល់ | `PK-261021-001` ចំនួន 40 គីឡូក្រាម ប្រសិនបើគ្មានចលនាផ្សេងទៀត |

ប្រសិនបើមានការព្រួយបារម្ភអំពីឡូត៍គ្រាប់ឆៅនេះ អាជីវកម្មអាចប្រើលេខសម្គាល់ដែលភ្ជាប់គ្នា ដើម្បីរកទំនិញនៅសល់ និងបញ្ជីការដឹកជញ្ជូនដែលពាក់ព័ន្ធសម្រាប់ការវាយតម្លៃបន្ថែម។ សៀវភៅកត់ត្រានេះមិនអាចសម្រេចដោយខ្លួនឯងថាត្រូវប្រមូលទំនិញត្រឡប់មកវិញឬអត់នោះទេ។

ឯកសារ Excel ពីរភាសានេះមានសេចក្តីណែនាំ តារាងទទួលឡូត៍ចូល តារាងភ្ជាប់ឡូត៍ចូលនិងចេញពីការកែច្នៃ តារាងដឹកជញ្ជូន និងឧទាហរណ៍។ សូមកត់មួយជួរសម្រាប់ព្រឹត្តិការណ៍ ឬទំនាក់ទំនងឡូត៍នីមួយៗ ហើយប្រើលេខឡូត៍ឱ្យស្របគ្នាជានិច្ច។ ត្រូវរក្សាវិក្កយបត្រ របាយការណ៍ត្រួតពិនិត្យ ប័ណ្ណថ្លឹង និងប័ណ្ណដឹកជញ្ជូនដែលបានយោងក្នុងតារាង។

គំរូនេះអាចកែសម្រួលតាមទំហំអាជីវកម្ម លក្ខខណ្ឌអ្នកទិញ និងតម្រូវការច្បាប់ដែលអនុវត្តនៅកម្ពុជា ឬទីផ្សារគោលដៅ។ វាមិនជំនួសការត្រួតពិនិត្យគុណភាព ប្រព័ន្ធសុវត្ថិភាពម្ហូបអាហារ គណនេយ្យ វិញ្ញាបនបត្រ ឬការប្រឹក្សាផ្នែកច្បាប់ឡើយ។
