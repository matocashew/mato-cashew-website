# សន្លឹកគណនាថ្លៃដើម និងកំណត់តម្លៃលក់តាមឡូត៍សម្រាប់អ្នកកែច្នៃស្វាយចន្ទីខ្នាតតូច

## ហេតុអ្វីត្រូវគណនាថ្លៃដើមតាមឡូត៍?

ការទិញគ្រាប់ស្វាយចន្ទីឆៅក្នុងតម្លៃដែលមើលទៅសមរម្យ មិនមានន័យថាការកែច្នៃនឹងទទួលបានប្រាក់ចំណេញជានិច្ចនោះទេ។ បន្ទាប់ពីចំហុយ បកសំបក សម្ងួត បកស្បែក តម្រៀបថ្នាក់ និងវេចខ្ចប់ អ្នកកែច្នៃអាចទទួលបានបរិមាណស្នូលចន្ទីសម្រាប់លក់តិចជាងការរំពឹងទុក ហើយក៏មានចំណាយលើកម្លាំងពលកម្ម ថាមពល និងការដឹកជញ្ជូនផងដែរ។

ធនធាននេះជាឧបករណ៍សម្រាប់ **គាំទ្រការសម្រេចចិត្តអាជីវកម្ម** មិនមែនជាមេរៀនបច្ចេកទេសស្តីពីការប្រើប្រាស់ម៉ាស៊ីនកែច្នៃទេ។ វាជួយឱ្យអ្នកកែច្នៃយល់ថា ឡូត៍មួយមានថ្លៃដើមប៉ុន្មាន តើស្នូលចន្ទីនីមួយៗមានតម្លៃលក់ខុសគ្នាយ៉ាងណា និងតើការលក់អាចគ្របដណ្តប់ចំណាយបានឬអត់។

## ១. កំណត់ឡូត៍ដែលត្រូវគណនា

ចាប់ផ្តើមពីឡូត៍ផលិតកម្មមួយដែលមានព្រំដែនច្បាស់លាស់។ កត់ត្រាលេខសម្គាល់ឡូត៍ កាលបរិច្ឆេទ បរិមាណគ្រាប់ស្វាយចន្ទីឆៅដែលបានបញ្ចូលកែច្នៃ (គីឡូក្រាម) និងថ្លៃទិញសរុប។ ប្រសិនបើទិញតាមគីឡូក្រាម ត្រូវយកបរិមាណគុណនឹងតម្លៃទិញក្នុងមួយគីឡូក្រាម។

បើមានថ្លៃដឹកជញ្ជូន ឬថ្លៃដោះដូរនៅពេលទិញដែលមិនទាន់បញ្ចូលក្នុងតម្លៃទិញ ត្រូវបូកបញ្ចូលទៅក្នុងថ្លៃដើមវត្ថុធាតុដើម។ **កុំរាប់ចំណាយដដែលពីរដង។** សូមកត់សម្គាល់ផងដែរថា ទម្ងន់ត្រូវបានវាស់នៅដំណាក់កាលណា ព្រោះការសម្ងួតអាចធ្វើឱ្យទម្ងន់ផ្លាស់ប្តូរ។

## ២. កត់ត្រាបរិមាណស្នូលចន្ទីដែលអាចលក់បាន

ក្រោយការកែច្នៃ និងតម្រៀបថ្នាក់ ត្រូវថ្លឹងស្នូលចន្ទីដែលបានបញ្ចប់ និងអាចលក់បានជាក់ស្តែង។ បែងចែកស្នូលពេញ ស្នូលបាក់ និងថ្នាក់ផ្សេងទៀត ដោយសារតម្លៃលក់អាចខុសគ្នា។ កុំយកលទ្ធផលតេស្តកាត់គ្រាប់នៅពេលទិញ មកចាត់ទុកថាជាបរិមាណស្នូលចន្ទីដែលរោងចក្រផលិតបានជាក់ស្តែង។

**អត្រាទទួលបានស្នូលចន្ទីសម្រាប់លក់ (%) = ទម្ងន់ស្នូលចន្ទីសម្រាប់លក់សរុប (គ.ក្រ.) ÷ ទម្ងន់គ្រាប់ឆៅដែលបានកែច្នៃ (គ.ក្រ.) × ១០០។**

នេះជាអត្រាដែលគណនាពីលទ្ធផលផលិតកម្មពិតប្រាកដ មិនដូចតម្លៃ KOR/Outturn ដែលវាស់ពីសំណាកគ្រាប់ឆៅសម្រាប់ការទិញដូរទេ។ ស្នូលដែលខូច ឬមិនអាចលក់បាន ត្រូវកត់ត្រាដោយឡែក។ ប្រសិនបើផលិតផលមិនទាន់លក់អស់ លទ្ធផលក្នុងសន្លឹកនេះគឺជាការ **ប៉ាន់ស្មានតាមសេណារីយ៉ូលក់អស់** មិនមែនជាប្រាក់ចំណេញដែលទទួលបានរួចទេ។

## ៣. បញ្ចូលចំណាយដែលពាក់ព័ន្ធ

ក្រៅពីថ្លៃទិញគ្រាប់ឆៅ ត្រូវកត់ត្រាចំណាយផ្ទាល់របស់ឡូត៍ ដូចជា ប្រាក់ឈ្នួលកម្មករ ថ្លៃអគ្គិសនី ឬឥន្ធនៈ ថ្លៃសម្ភារៈវេចខ្ចប់ ថ្លៃដឹកជញ្ជូន និងសម្ភារៈប្រើប្រាស់ផ្សេងៗ។ ប្រសិនបើចង់គណនាថ្លៃដើមពេញលេញ គួរបែងចែកចំណាយថេរដែលពាក់ព័ន្ធ ដូចជា ថ្លៃជួល ការរំលស់ម៉ាស៊ីន ការថែទាំ និងរដ្ឋបាល ទៅតាមវិធីសាស្ត្រសមស្រប។

ឧទាហរណ៍ អាជីវកម្មអាចបែងចែកចំណាយថេរប្រចាំខែតាមទម្ងន់គ្រាប់ឆៅដែលបានកែច្នៃ ឬតាមម៉ោងដំណើរការម៉ាស៊ីន។ ត្រូវប្រើវិធីសាស្ត្រដដែលឱ្យបានស្របគ្នា។ ចំណាយការប្រាក់ ពន្ធ សេវាហិរញ្ញប្បទាន ការគ្រប់គ្រងសំណល់ និងទីផ្សារ អាចត្រូវបញ្ចូលបន្ថែមតាមស្ថានភាពជាក់ស្តែង។

**ថ្លៃដើមសរុបតាមឡូត៍ = ថ្លៃវត្ថុធាតុដើម + ចំណាយកែច្នៃ និងលក់ដែលប្រែប្រួល + ចំណាយថេរដែលបានបែងចែក។**

## ៤. គណនាចំណូល និងតម្លៃលក់ដើម្បីគ្របដណ្តប់ថ្លៃដើម

យកបរិមាណស្នូលចន្ទីដែលរំពឹងថាលក់បានតាមថ្នាក់នីមួយៗ គុណនឹងតម្លៃលក់ក្នុងមួយគីឡូក្រាម រួចបូកចូលគ្នា។ បើមានចំណូលពីផលិតផលរង អាចបញ្ចូលបានតែនៅពេលមានអ្នកទិញ និងមានមូលដ្ឋានប៉ាន់ស្មានចំណូលសុទ្ធដែលអាចទទួលបាន។ បើមិនប្រាកដ សូមបញ្ចូលសូន្យ។

**ចំណូលប៉ាន់ស្មាន = ផលបូកនៃ (ទម្ងន់ស្នូលតាមថ្នាក់ × តម្លៃលក់តាមថ្នាក់) + ចំណូលសុទ្ធពីផលិតផលរងដែលអាចទទួលបាន។**

**លទ្ធផលឡូត៍ប៉ាន់ស្មាន = ចំណូលប៉ាន់ស្មាន − ថ្លៃដើមសរុប។**

**ថ្លៃដើមក្នុងមួយគីឡូក្រាមស្នូលចន្ទី = (ថ្លៃដើមសរុប − ចំណូលសុទ្ធពីផលិតផលរង) ÷ ទម្ងន់ស្នូលចន្ទីសម្រាប់លក់សរុប។**

តម្លៃចុងក្រោយនេះអាចប្រើជាតម្លៃលក់មធ្យមអប្បបរមា ដើម្បីគ្របដណ្តប់ចំណាយដែលបានរាប់បញ្ចូល **ប្រសិនបើស្នូលចន្ទីទាំងអស់ដែលបានគណនាត្រូវបានលក់** និងមិនមានចំណាយបន្ថែម។ វាមិនមែនជាតម្លៃទីផ្សារផ្លូវការ ឬការវិភាគចំណុចរួចខ្លួនប្រចាំខែរបស់អាជីវកម្មទាំងមូលទេ។

## ៥. ឧទាហរណ៍គណនា — លេខសម្រាប់បង្រៀនប៉ុណ្ណោះ

សន្មតថាអ្នកកែច្នៃម្នាក់ប្រើគ្រាប់ស្វាយចន្ទីឆៅ **១,០០០ គីឡូក្រាម** ក្នុងតម្លៃ **១.២០ ដុល្លារ/គីឡូក្រាម**។ ក្រោយកែច្នៃ ទទួលបានស្នូលពេញ **១៥០ គីឡូក្រាម** និងស្នូលបាក់ **៨០ គីឡូក្រាម** ដែលអាចលក់បាន។ សន្មតថាស្នូលពេញលក់បាន **៨.០០ ដុល្លារ/គីឡូក្រាម** និងស្នូលបាក់ **៥.០០ ដុល្លារ/គីឡូក្រាម**។ **តួលេខទាំងនេះជាឧទាហរណ៍សន្មត មិនមែនជាតម្លៃទីផ្សារកម្ពុជាបច្ចុប្បន្ន ឬស្តង់ដារទិន្នផលនោះទេ។**

| មុខទិន្នន័យ | របៀបគណនា | លទ្ធផលឧទាហរណ៍ |

| អត្រាទទួលបានស្នូល | ២៣០ ÷ ១,០០០ × ១០០ | ២៣.០% |
| ចំណូលស្នូលពេញ | ១៥០ × $៨.០០ | $១,២០០.០០ |
| ចំណូលស្នូលបាក់ | ៨០ × $៥.០០ | $៤០០.០០ |
| ចំណាយប្រែប្រួល (កម្មករ ថាមពល វេចខ្ចប់ ដឹកជញ្ជូន និងផ្សេងៗ) | $៨០ + $៣៥ + $២០ + $២៥ + $១០ | $១៧០.០០ |
| ចំណាយថេរដែលបានបែងចែក | សន្មត | $៦០.០០ |
| ថ្លៃដើមសរុប | $១,២០០ + $១៧០ + $៦០ | $១,៤៣០.០០ |
| ចំណូលសរុបប៉ាន់ស្មាន | $១,២០០ + $៤០០ | $១,៦០០.០០ |
| លទ្ធផលឡូត៍ប៉ាន់ស្មាន | $១,៦០០ − $១,៤៣០ | **$១៧០.០០** |
| តម្លៃលក់មធ្យមដើម្បីគ្របដណ្តប់ថ្លៃដើម | $១,៤៣០ ÷ ២៣០ | **$៦.២២/គ.ក្រ.** |
| អត្រាចំណេញលើចំណូលប៉ាន់ស្មាន | $១៧០ ÷ $១,៦០០ × ១០០ | **១០.៦%** |

ឧទាហរណ៍នេះបង្ហាញថា ត្រូវមើលទាំងបរិមាណស្នូលពេញ និងស្នូលបាក់ ព្រោះតម្លៃលក់ខុសគ្នា។ មិនគួរយកតម្លៃលក់ស្នូលថ្នាក់ខ្ពស់បំផុតមកប្រៀបធៀបជាមួយថ្លៃគ្រាប់ឆៅតែមួយមុខនោះទេ។

## ៦. ប្រើសន្លឹកគណនាមុនទិញ និងមុនដាក់តម្លៃលក់

មុនទិញគ្រាប់ឆៅ សូមបញ្ចូលការប៉ាន់ស្មានទិន្នផលដោយប្រុងប្រយ័ត្ន ដោយយោងលើកំណត់ត្រាឡូត៍មុនៗរបស់អាជីវកម្ម។ សាកល្បងប្តូរតម្លៃគ្រាប់ឆៅ បរិមាណស្នូលពេញ និងបាក់ ថ្លៃថាមពល និងតម្លៃដែលអ្នកទិញផ្តល់ជូន ដើម្បីមើលថាលទ្ធផលផ្លាស់ប្តូរយ៉ាងណា។

មុនយល់ព្រមលើតម្លៃលក់ ត្រូវជំនួសការប៉ាន់ស្មានដោយចំណាយពិតប្រាកដនៅពេលមានទិន្នន័យ។ កត់ត្រារូបិយប័ណ្ណ លក្ខខណ្ឌដឹកជញ្ជូន ការបញ្ចុះតម្លៃ កម្រៃជើងសារ និងពន្ធដែលអាចពាក់ព័ន្ធ។

## ៧. រក្សាកំណត់ត្រាមួយសម្រាប់ឡូត៍នីមួយៗ

សន្លឹកកំណត់ត្រាគួរមានលេខឡូត៍ កាលបរិច្ឆេទ ទម្ងន់ និងថ្លៃទិញគ្រាប់ឆៅ ទម្ងន់ស្នូលតាមថ្នាក់ តម្លៃលក់ ចំណាយប្រែប្រួល ចំណាយថេរដែលបានបែងចែក និងលទ្ធផលគណនា។ គួររក្សាវិក្កយបត្រ និងកំណត់ត្រាថ្លឹងទម្ងន់សម្រាប់ផ្ទៀងផ្ទាត់។

ពេលលក់ផលិតផលអស់ហើយ សូមប្រៀបធៀបចំណូល និងចំណាយពិតជាមួយការប៉ាន់ស្មានដំបូង។ សន្លឹកគណនាថ្លៃដើមអាចយោងលេខឡូត៍ដែលមានស្រាប់ ប៉ុន្តែ **មិនជំនួសប្រព័ន្ធតាមដានប្រភពដើម និងការចែកចាយផលិតផល (traceability)** ទេ។
